PLOTLINE 2.2 — Real Surveying & Property Development

This is a separate development build based on the working PLOTLINE 2.1 prototype.

New in 2.2:
- Interactive parcel sketch canvas: tap to add up to 20 parcel corners.
- Numeric coordinate editor for each corner (Northing/Easting, feet).
- Parcel area in square feet and acres, perimeter, closure-to-start check.
- Calculated quadrant bearings and horizontal distances for each course.
- Sample parcel, undo, clear, and local save through the existing browser save system.
- Existing 2.1 Academy, Must See review, Job Log, business progression, and finance features retained.

Important limitations:
- This is a prototype planar-coordinate parcel designer, not a legal boundary survey or CAD/GIS replacement.
- Sketch points are conceptual. No datum/projection, grid-to-ground, elevation datum, monument evidence, or survey-grade accuracy is claimed.
- The parcel workspace uses US feet and browser-local storage. Keep 2.1 as your backup and test 2.2 separately before replacing the live main page.

To test on GitHub Pages, upload the contents of this folder to a separate branch or test repository, or open index.html locally. Do not overwrite your current main index.html until the test passes.
